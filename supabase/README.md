# Supabase

Guardar aquí las migraciones SQL revisadas por el equipo. La conexión se configura en `apps/api/.env` mediante `DATABASE_URL`; no guardar credenciales en este directorio.

Al implementar el primer módulo con persistencia, definir las tablas y restricciones a partir de sus casos de uso y versionar la migración correspondiente. Mantener la dirección exacta y los documentos privados fuera de las respuestas públicas de la API.
